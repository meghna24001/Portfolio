# Meghna Ghosh — Portfolio

A personal portfolio website introducing me, my education, skills, and projects. It is built with plain HTML, CSS, and JavaScript.

## Contents

- About and education
- Skills
- Project highlights, including the Finance Dashboard
- Contact links

## Built with

- HTML
- CSS
- JavaScript

## Run locally

No build step or dependencies are required. Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/meghna24001/Portfolio.git
cd Portfolio
```

Alternatively, serve the project directory with any static web server.

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, and select the `main` branch and the `/(root)` folder. The site will be published at:

<https://meghna24001.github.io/Portfolio/>
